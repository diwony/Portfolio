# 김지원 | Portfolio

정적 포트폴리오 웹사이트입니다. `index.html`, `styles.css`, `script.js`, `assets/`로 구성된 순수 HTML/CSS/JS 프로젝트입니다.

## 로컬에서 보기

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## 구조

- `index.html` — 페이지 마크업
- `styles.css` — 스타일
- `script.js` — 스크롤 리빌 등 인터랙션
- `assets/` — 폰트, 이미지, SVG, 영상
- `figma-DESIGN.md` — 디자인 사양 메모
